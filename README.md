# 🌠 Offer降临

一个为秋招季设计的移动端 H5 许愿小游戏。

写下自己的 Offer 愿望，等待流星捕获信号，转动「Offer 大满贯」星辰转盘，领取专属 Offer 星辰签。

## 特色

- 星空粒子与多方向流星动画
- 三阶段许愿仪式
- 17 格秋招去向转盘，包含互联网公司、硬件厂商、银行、研究所和外企
- 真实减速与随机落点
- 星辰签、祝福语、烟花和系统分享
- 移动端优先，适配 iPhone 安全区域
- 程序员风格隐藏彩蛋

## 使用

直接用浏览器打开根目录的 `index.html` 即可。页面不依赖后端、构建工具或外部资源。
